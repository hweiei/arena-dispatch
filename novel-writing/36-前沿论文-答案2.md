### 条目 2：7 叙事学理论・认知叙事学、不可靠叙述与叙述距离

1. 争论轴：A 方强调读者主动建构叙事意义的自下而上模型；B 方强调文本结构预设引导意义生成的自上而下模型。检索词：中文 认知叙事学 叙事意义 读者建构 过程模型；英文 cognitive narratology narrative meaning construction process model。去哪查：文学认知研究数据库

**为什么**：利用 AI 辅助创作长篇故事时，创作者经常遇到人设崩坏、情节偏离设定等问题。了解不同可控生成路线的优劣，能选择合适方案约束模型产出，而不是单纯依赖提示词。可以预判世界观、角色、情节多约束叠加时可能产生的矛盾，提前设计冲突处理机制。当中途修改故事设定时，能够评估叙事重规划的代价与可行性。

**怎么做**：
1. 争论轴：A 方认为依靠精细化提示词即可稳定约束长篇叙事；B 方认为需要外部记忆、叙事规划等多层机制共同约束。检索词：中文 LLM 可控长篇叙事生成 提示词 外部记忆；英文 controllable long narrative generation prompt external memory。去哪查：计算叙事、生成式 AI 数据库
2. 争论轴：A 方认为可以独立编码角色、世界观、情节约束并自动消解冲突；B 方认为多约束天然存在冲突，需要人工优先规则干预。检索词：中文 可控叙事生成 多约束冲突；英文 controllable narrative generation multi-constraint conflict。去哪查：交互式叙事技术文献库
3. 争论轴：A 方认为基于规划的叙事生成稳定性更强；B 方认为直接续写灵活性更高，规划方案会扼杀叙事自然感。检索词：中文 叙事规划生成 LLM 续写 优势失效场景；英文 narrative planning vs LLM continuation advantage failure case。去哪查：计算叙事专题论文集
4. 争论轴：A 方认为可以同时精确控制视角、叙述距离与风格，互不干扰；B 方认为多重风格约束会互相干扰，损害文本自然度。检索词：中文 LLM 叙事生成 叙事视角 叙述距离 风格控制；英文 LLM narrative generation point of view narrative distance style control。去哪查：AI 文本生成研究数据库
5. 争论轴：A 方认为分支交互式叙事适合采用规划驱动框架；B 方认为适合采用轻量条件提示生成框架。检索词：中文 交互式分支叙事 可控生成 技术路线；英文 interactive branching narrative controllable generation technical approach。去哪查：游戏叙事与数字叙事数据库
6. 争论轴：A 方认为可以直接用约束指令引导模型产出不可靠叙述、非自然叙事；B 方认为这类特殊叙事需要专门的叙事表征模块。检索词：中文 LLM 约束生成 不可靠叙述 非自然叙事；英文 LLM constrained generation unreliable narration unnatural narrative。去哪查：叙事学与 AI 交叉学位论文库
7. 争论轴：A 方认为外部存储器重点记录角色、世界观、关键情节事实；B 方认为还需要记录叙事意图与主题方向等高层信息。检索词：中文 外部叙事状态存储器 长篇叙事一致性；英文 external narrative state memory long narrative consistency。去哪查：长篇文本生成技术文献库
8. 争论轴：A 方认为用户修改设定时可以自动完成全局叙事重规划；B 方认为中途改设定仅支持局部修正，全局重规划成本极高。检索词：中文 可控叙事生成 中途修改设定 叙事重规划；英文 controllable narrative mid-story setting revision replanning。去哪查：交互式叙事会议论文库
9. 争论轴：A 方认为风格约束和情节约约束可以独立优化；B 方认为二者存在固有权衡，强化一方会削弱另一方。检索词：中文 叙事生成 风格约束 情节约束 权衡；英文 narrative generation style constraint plot constraint trade-off。去哪查：大模型可控生成数据库
10. 争论轴：A 方认为可以构建独立轻量控制器实时监控修正叙事偏离；B 方认为偏离检测本身存在判断误差，控制器难以稳定生效。检索词：中文 LLM 续写 叙事偏离 轻量级控制器；英文 LLM continuation narrative deviation lightweight controller。去哪查：AI 文本校验、计算人文文献库

**反例**：创作者看到教程说 “多写几条提示就能锁定角色人设和世界观”，只依靠提示词约束长篇 AI 小说，没有外部状态存储，随着故事推进角色行为、世界观规则不断偏离初始设定，难以修正。
