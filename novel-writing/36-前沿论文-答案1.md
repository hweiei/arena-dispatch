### 条目 1：认知与心理机制・读者叙事加工的认知基础

**原则**：围绕读者阅读叙事文本时内部信息处理、心理模型搭建的认知过程，探讨时序、个体差异、推理与认知负荷等相关分歧。

**为什么**：小说作者设计情节排布、信息放出节奏、背景交代篇幅时，需要预判读者接收与理解故事信息的方式。理解这类争议，能避免信息铺排超出读者认知处理能力，也可主动利用认知规律安排线索。同时帮助区分哪些叙事写法会加重读者负担，哪些写法利于读者快速建立故事场景。还可以在构思长篇故事时，预估读者追踪伏笔、接收设定的局限。

1. 争论轴：一方主张语义激活先行，再逐步建构情景；另一方认为情景框架会预先约束语义激活的时序。检索词：中文 叙事阅读 语义激活 情景建构 时序；英文 narrative reading semantic activation situation construction temporal sequence。去哪查：心理学、认知语言学学术数据库
2. 争论轴：一方认为各类叙事信息仅在加工速度上存在差别；另一方主张不同类型信息会造成心理模型完整性的质的区别。检索词：中文 叙事信息类型 心理模型 构建；英文 narrative information type mental model construction。去哪查：认知科学、阅读研究专业文献平台
3. 争论轴：一方认为工作记忆容量直接决定线索追踪上限；另一方认为叙事结构设计可以缓冲工作记忆不足带来的追踪缺陷。检索词：中文 工作记忆容量 长篇叙事 线索追踪；英文 working memory capacity long narrative trace tracking。去哪查：心理学全文数据库
4. 争论轴：一方偏向用认知抑制机制解释冲突消解；另一方主张依靠模型更新机制完成矛盾信息处理。检索词：中文 叙事阅读 认知冲突 消解 理论；英文 narrative comprehension cognitive conflict resolution theory。去哪查：认知心理学、语篇理解文献库

7. 争论轴：一方认为背景冗余与认知负荷呈线性增长；另一方认为二者是非线性关系，适度冗余反而降低负荷。检索词：中文 叙事背景信息 冗余 认知负荷 非线性；英文 narrative background information redundancy cognitive load nonlinearity。去哪查：认知语言学、人因学文献库

### 条目 2：认知与心理机制・叙事情感唤起与情绪动态演化

**原则**：探究叙事文本如何唤起读者情绪、情绪随阅读推进的变化规律，以及情绪和文本要素、读者个体特征之间的分歧观点。

1. 争论轴：一方认为悬念和角色困境共用同一套情绪唤起通路；另一方认为二者分别激活不同类型情绪通路。检索词：中文 叙事悬念 角色困境 情绪唤起路径；英文 narrative suspense character dilemma emotional arousal pathway。去哪查：认知心理学、文学情感研究数据库

### 条目 4：认知与心理机制・叙事内容的记忆编码、保持与遗忘

**原则**：研究读者阅读叙事时故事信息如何存入记忆、随时间衰减，以及回忆时出现重构、扭曲等现象，梳理相关分歧观点。

**为什么**：长篇小说设计伏笔、线索回收、情节呼应，本质上是和读者叙事记忆打交道。了解记忆相关争议，可以合理控制伏笔放置间隔，判断哪些细节读者容易记住或遗忘。帮助预判读者回忆故事时可能出现的记忆扭曲，避免依赖读者自行脑补的信息。还能利用情绪、悬念等要素，调控核心情节与次要细节的记忆留存差异。

**怎么做**：
1. 争论轴：一方认为核心情节和次要细节采用完全不同编码系统；另一方认为二者共享编码系统，仅在加工深度上存在区别。检索词：中文 叙事 核心情节 次要细节 记忆编码；英文 narrative core plot minor detail memory encoding。去哪查：认知记忆、语篇理解数据库
2. 争论轴：一方认为叙事情绪强度越高记忆巩固越强；另一方认为过高情绪反而会损害部分信息巩固，加速遗忘。检索词：中文 叙事情绪强度 记忆巩固 遗忘；英文 narrative emotional intensity memory consolidation forgetting。去哪查：记忆心理学、文学认知文献平台
3. 争论轴：一方认为回忆扭曲源于原始编码缺陷；另一方认为扭曲产生在回忆重构阶段，由常识推断介入造成。检索词：中文 叙事回忆 记忆扭曲 常识推断；英文 narrative recall memory distortion commonsense inference。去哪查：认知记忆全文数据库
4. 争论轴：一方认为前后线索呼应能够稳定延缓远期情节遗忘；另一方认为呼应效果受线索强度与间隔长度制约，不一定生效。检索词：中文 叙事线索呼应 远期情节遗忘；英文 narrative cue coherence remote plot forgetting。去哪查：语篇记忆、叙事认知文献库
