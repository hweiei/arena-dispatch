### 条目 1：21 创作过程与作者研究・创作认知

**原则**：围绕网络小说连载写作场景，探究作者叙事构思、灵感生成、记忆调用、读者预判等一系列创作活动背后的认知运作方式。

**为什么**：理解创作认知的不同模式，能帮助创作者判断自身写作习惯的局限，区分稳定构思和即兴写作各自适用的故事阶段。可以让作者识别连载过程中认知资源消耗的信号，提前规划写作节奏。也能理性看待灵感、卡文等主观创作体验背后的认知机制，不盲目迷信单一创作法门。同时帮助作者区分自己对读者的预判和真实读者反馈之间的偏差。

**怎么做**：
1. 争论轴：一方认为连载叙事规划属于前瞻式的预演认知加工，另一方认为属于边生成边修正的动态建构加工。检索词：中文 网络小说 连载 叙事规划 认知加工；英文 web novel serial writing narrative planning cognitive processing。去哪查：中文人文社科数据库、心理学学术数据库
2. 争论轴：一方主张人物情节构思以具象心理表征为主，另一方主张以命题式抽象表征为主。检索词：中文 文学构思 心理表征 人物 情节；英文 literary mental representation character plot conception。去哪查：心理学全文数据库、文学研究学术平台

4. 争论轴：一方认为即兴写作认知负荷更高，另一方认为预先大纲写作维持整体设定会带来更高认知负荷。检索词：中文 网文 大纲写作 即兴写作 认知负荷；英文 web novel outline writing impromptu writing cognitive load。去哪查：认知心理学数据库、数字出版研究平台

7. 争论轴：一方认为连载带来的认知消耗呈现线性累积，另一方认为消耗是阶段性波动，存在认知代偿区间。检索词：中文 长期连载 写作 认知资源消耗；英文 serial fiction writing cumulative cognitive resource depletion。去哪查：人文与心理学联合检索平台
8. 争论轴：一方认为读者预期预判在构思早期就深度介入，另一方认为预判只在修改、调整剧情阶段发挥作用。检索词：中文 网文作者 读者预期 叙事构思 认知；英文 fiction writer reader expectation narrative conception cognition。去哪查：数字人文、网络文学专题文献库
9. 争论轴：一方将虚构世界设定认知策略分为规则优先型，另一方分为角色体验优先型，还有其他分类方案。检索词：中文 虚构世界建构 认知策略 类型；英文 fictional world building cognitive strategy typology。去哪查：叙事学数据库、创意写作研究平台

### 条目 2：22 创作过程与作者研究・写作过程模型

**原则**：针对网络文学边写边更的连载形态，考察通用写作过程模型的适配性、阶段划分、变量关系与模型修正方案。

**为什么**：写作过程模型可以帮创作者把模糊的写作感受拆解成可识别的创作阶段，看清自己的写作行为处在哪个环节。借助模型框架，作者能够定位修改主线、调整设定这类重大改动发生在创作链条中的位置。当使用写作辅助工具时，可以评估工具会干预写作流程中的哪些环节，预判带来的变化。也可以对照模型，对比稳定完本与中途弃稿的创作轨迹差异，识别风险节点。

**怎么做**：
1. 争论轴：一方认为传统写作过程模型经过微调就可以解释网文连载，另一方认为连载的持续反馈机制让经典模型基本失效。检索词：中文 写作过程模型 网络文学 连载；英文 writing process model web fiction serial publication。去哪查：中文文学研究数据库、应用语言学文献库
2. 争论轴：一方主张连载写作可划分为固定顺序的离散阶段，另一方主张各阶段持续交织、动态跳转，不存在严格先后顺序。检索词：中文 网文连载写作 创作阶段 动态切换；英文 serial web novel writing stages dynamic transition。去哪查：数字人文文献库、创意写作学术平台
3. 争论轴：一方将读者反馈视为外部输入变量，另一方认为读者反馈会内化为作者认知变量嵌入写作循环。检索词：中文 读者反馈 写作过程模型 变量；英文 reader feedback writing process model variable。去哪查：人文社科综合数据库
4. 争论轴：一方认为大纲驱动与即兴写作只是参数差异，底层写作模型一致，另一方认为二者拥有完全不同的过程结构。检索词：中文 大纲写作 即兴写作 写作过程模型；英文 outline-driven writing spontaneous writing process model structural difference。去哪查：应用语言学、创意写作数据库
5. 争论轴：一方认为主线设定修改是模型内部阶段自然迭代的结果，另一方认为重大改动属于外部扰动，打破原有写作循环。检索词：中文 小说创作 修改主线设定 写作过程模型；英文 fiction major plot revision writing process model。去哪查：叙事研究、创意写作文献库
6. 争论轴：一方偏好键盘日志、文稿版本记录等客观时序采集方式，另一方认为需要搭配访谈，单纯文本时序记录缺少主观意图信息。检索词：中文 写作过程 时序记录 数据采集方法；英文 writing process timeline data collection method。去哪查：数字人文、计算人文数据库
7. 争论轴：一方认为写作速度差异对应模型各阶段耗时比例变化，另一方认为快慢作者在阶段切换逻辑上存在本质区别。检索词：中文 写作速度 写作过程模型 参数；英文 writing speed writing process model parameter difference。去哪查：应用语言学、写作认知研究平台
8. 争论轴：一方认为写作辅助工具只是替换部分子步骤，原有写作模型仍可保留；另一方认为工具重构创作流程，需要全新模型框架。检索词：中文 AI 写作辅助工具 写作过程模型 修正；英文 writing aid tool writing process model revision。去哪查：数字出版、创意写作文献库

### 条目 3：23 创作过程与作者研究・作者身份与署名

**原则**：在网文平台、多人协作与 AI 辅助等复杂条件下，考察作者身份的建构、变化、认定标准以及身份叙事带来的各类影响。

**为什么**：理清作者身份的不同维度，能帮助作者主动规划笔名、人设，管理读者对自己的认知印象。面对代笔、多人合写、AI 辅助等情况，可参考相关讨论判断署名对应的权责边界，规避争议。理解身份商品化的讨论，帮助创作者理性看待平台流量、读者评价对自我认知带来的持续塑造。也可以区分作者自我认知和读者眼中作者形象之间的偏差，减少预期落差。

**怎么做**：
1. 争论轴：一方认为网文作者身份以平台账号与署名文本为核心，另一方认为作者身份是读者、平台、文本共同建构的复合产物。检索词：中文 网络文学 作者身份建构 影响因素；英文 web literature author identity construction dimension。去哪查：文艺学、媒介文化研究数据库
2. 争论轴：一方认为多笔名会拆分作者身份认同，造成自我割裂；另一方认为多笔名是身份策略，拓展创作空间而不损害核心认同。检索词：中文 多笔名 网文作者 身份认同；英文 multiple pen names web fiction author identity。去哪查：媒介研究、网络文学专题文献库
3. 争论轴：一方主张署名只对应最终文本责任人，另一方主张作者身份要按照实际创意贡献程度判定，不唯署名。检索词：中文 网络文学 代笔 多人协作 作者身份界定；英文 ghostwriting collaborative writing authorship definition web fiction。去哪查：文艺理论、媒介与版权研究数据库
4. 争论轴：一方认为读者认知作者形象是文本衍生的副产品，另一方认为读者建构的作者形象会反向影响文本解读。检索词：中文 网文 读者认知 作者形象 身份错位；英文 web fiction perceived author image identity dissonance。去哪查：接受美学、数字人文文献库
5. 争论轴：一方认为流量与评价被动改变作者身份定位，另一方认为作者拥有能动性，可以选择性接纳或抵抗平台与读者塑造。检索词：中文 网络文学 流量 读者评价 作者身份；英文 web fiction traffic reader evaluation author identity formation。去哪查：媒介文化、数字出版数据库
6. 争论轴：一方将作者身份商品化视为资本异化，另一方将其看作数字内容场域里创作者自主经营的身份资产。检索词：中文 网络文学 作者身份 商品化 分析视角；英文 web literature author identity commodification perspective。去哪查：文化研究、政治经济学文献库
7. 争论轴：一方将匿名 / 半匿名策略划分为保护隐私型，另一方划分为维持文本优先、弱化个人形象的叙事策略。检索词：中文 网文 匿名 半匿名 身份表达策略；英文 web fiction anonymous semi-anonymous author identity strategy。去哪查：网络文化研究、叙事学数据库

### 条目 4：24 创作过程与作者研究・创作障碍

**原则**：聚焦网络连载场景，梳理创作障碍的类型、成因、影响因素、应对策略以及相关研究方法存在的局限。

**为什么**：系统区分不同类型的创作障碍，可以帮助作者定位自己卡文、不想动笔背后的诱因，而不是笼统归因为缺乏灵感。了解读者评论、更新压力与创作障碍之间的作用讨论，帮助作者建立合理的心理预期，减少负面反馈带来的冲击。认识不同应对策略的讨论，方便作者按需尝试适合自己的脱困方式，避免单一无效自救手段。同时可以理性评估 AI 工具在缓解卡文上的两面可能性，不盲目依赖。

**怎么做**：
1. 争论轴：一方主张按心理情绪维度划分连载创作障碍，另一方主张以叙事任务受阻类型作为分类标准。检索词：中文 网络连载 创作障碍 类型 测量；英文 serial web writing writer’s block classification measurement。去哪查：创意写作、文艺心理学数据库
2. 争论轴：一方认为负面评论直接诱发创作障碍，另一方认为负面评论仅在特定个人认知条件下才会触发障碍。检索词：中文 网文 负面读者评论 创作障碍；英文 web fiction negative reader comments writer’s block。去哪查：媒介心理学、网络文学文献库
3. 争论轴：一方认为更新压力与连载时长和创作障碍发生概率呈简单正向相关，另一方认为存在临界点效应，超过阈值后风险快速上升。检索词：中文 网文 更新压力 连载时长 创作障碍；英文 web fiction update pressure serial duration writer’s block。去哪查：数字人文、创意写作研究平台
4. 争论轴：一方认为卡文源于工作记忆过载，另一方认为源于叙事概念网络断裂，还有其他认知成因假说。检索词：中文 小说卡文 创作障碍 认知成因；英文 writer’s block narrative writing cognitive cause hypothesis。去哪查：创作认知、叙事学数据库
5. 争论轴：一方认为题材套路固化会形成特殊创作障碍，限制创意发散；另一方认为套路是叙事脚手架，不会构成障碍。检索词：中文 网文 题材套路固化 创作障碍；英文 web fiction genre formula solidification writer’s block。去哪查：类型文学、网络文学专题文献库
6. 争论轴：一方认为低自我效能感是创作障碍的结果，另一方认为低自我效能感是诱发创作障碍的前置原因。检索词：中文 创作障碍 写作自我效能感 相互作用；英文 writer’s block writing self-efficacy interaction。去哪查：教育心理学、创意写作数据库

### 条目 5：25 类型与跨媒介・网络小说类型体系演化机制

**原则**：考察平台算法、读者、作者、规则等多方力量如何共同推动网络小说类型体系的分化、融合、迭代与消亡。

**为什么**：理解网文类型演化的动力来源，能帮助创作者预判题材趋势，判断自己构思的故事在现有类型体系里的位置。认识标签、读者评论、平台审核对类型边界的塑造作用，方便作者设计类型混搭叙事，评估创新的风险。学习识别类型核心要素的思路，让作者分清必须遵守的类型惯例和可以自由改动的表层装饰元素。同时可以理解小众题材突围需要的条件，理性评估新亚型创作的难度。

**怎么做**：
1. 争论轴：一方认为推荐算法是网文类型演化的核心驱动力，另一方认为算法只是放大读者偏好，底层类型变化来自读者与作者群体。检索词：中文 推荐算法 网络小说 类型演化；英文 recommendation algorithm web novel genre evolution differentiation fusion。去哪查：数字人文、计算传播学数据库
2. 争论轴：一方认为读者标签与评论是新亚型诞生的源头，另一方认为标签只是事后归类，新亚型起源于作者群体的叙事创新。检索词：中文 网文 读者评论 标签 新亚型；英文 web fiction reader comment tagging new subgenre emergence。去哪查：数字人文、网络文学专题文献库
3. 争论轴：一方认为经典文学类型迁移到网文场域只是形式载体变化，叙事内核不变；另一方认为网文连载模式会彻底重构类型的叙事规则。检索词：中文 经典文学类型 网络文学 规则重构；英文 classic literary genre migration web fiction rule reconstruction。去哪查：比较文学、叙事学数据库
4. 争论轴：一方认为内容审核规则直接划定类型边界，另一方认为审核规则只是约束表达，类型边界主要由市场与读者塑造。检索词：中文 网文 内容审核 类型边界塑造；英文 web fiction content review genre boundary formation platform difference。去哪查：媒介文化、数字出版文献库
5. 争论轴：一方认为类型混搭只要叙事逻辑自洽就能形成稳定亚型，另一方认为需要匹配受众认知与平台传播条件才可以稳定留存。检索词：中文 网文 类型混搭 叙事 亚型形成；英文 web fiction genre hybrid narrative stable subgenre。去哪查：类型文学、数字人文数据库
6. 争论轴：一方认为类型迭代是作者群体共识推进，另一方认为类型范式迭代伴随不同创作派系之间持续博弈。检索词：中文 网文 类型范式迭代 作者群体博弈；英文 web fiction genre paradigm iteration author group contestation。去哪查：文化研究、网络文学文献库
7. 争论轴：一方主张依靠文本特征统计量化提取类型核心叙事要素，另一方认为类型核心要素包含读者认知，不能只靠文本计算。检索词：中文 网络小说 类型 核心叙事要素 量化识别；英文 web novel genre core narrative element quantitative identification。去哪查：计算人文、叙事学数据库
